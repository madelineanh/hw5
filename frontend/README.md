# Campus Customs Service Desk (React + Vite + TypeScript)

The dashboard for the Campus Customs agent team. It calls the FastAPI backend at `http://localhost:8000` (override with `VITE_API_URL`).

```bash
npm install
npm run dev   # http://localhost:5173  (?ticket=101 opens a ticket)
```

Design notes: `../output/design.md`.
